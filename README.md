# Proyecto prueba login

Login de práctica que funciona solo en el navegador (HTML, CSS y JavaScript), hecho para aprender a usar Claude Code y GitHub.

## Cómo abrirlo
Haz doble clic en `index.html` para abrirlo en el navegador.

Usuario de prueba: `admin` / `1234`

> Es solo para aprender: las credenciales están en el código y no es seguro para uso real.
